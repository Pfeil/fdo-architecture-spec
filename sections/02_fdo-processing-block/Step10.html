[S-10]: FDO Data Access

This step attempts to return the FDO’s data bit-sequence or its location. It assumes that was completed and that its status indicates that a 0.FDO/Data field is present.
Inputs
This step expects that had a Mandatory_Attributes_Status of COMPLETE, DATA_ONLY, TYPE_MISSING, or PROFILE_MISSING. This step expects the output of : exactly one well-structured FDO record.
Outputs
Depending on the value of the 0.FDO/Data field, the output is one of the following:
  • the string self
  • an object Data which consists of
    • a list Inline_Data containing inline data bit-sequences
    • a list Data_Locations containing web locations where data bit-sequences are stored
  • a null value
Expected behavior
The client locates all 0.FDO/Data attributes in the FDO record and performs the following steps for each of them. Having more than one 0.FDO/Data means that this FDO contains a collection of resources.
  • The data attribute either contains the string self, or it uses attribute referencing.
    • If the value of 0.FDO/Data is self, self is returned, indicating to the client that the FDO record is itself regarded as the data bit-sequence. In this case there must not be more than one 0.FDO/Data in the record.
    • If the attribute referencing mechanism is applied, the client reads the value of 0.FDO/Data and checks which other attribute(s) the data attribute is pointing to. For each referenced attribute, the attribute definition of the referenced attribute is inspected to find out how the data are typed.
      • If the attribute definition specifies that the data is at a certain web location, this location is stored in Data_Locations.
      • If the attribute definition specifies that the data is in-line, the inline data are stored in Inline_Data.
      • If the attribute definition specifies that the data is within its own FDO (which could be either an inline-FDO or a reference to an FDO), the client accesses this FDO and recurses until it finds either a 0.FDO/Data attribute with the value self, with an in-line data bit-sequence, with a web-location or an invalid FDO.
      • If the attribute referencing mechanism fails such that no data locations or inline data can be found, a null value is returned.
The client SHOULD make the best effort to provide the means to access the data depending on the manner in which the FDO references its data.
