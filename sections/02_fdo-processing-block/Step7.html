[S-7]: FDO Profile Cardinality Validation

Each attribute definition specifies a cardinality with which the respective attribute is allowed to occur in an FDO record. If an attribute definition is part of a profile, the cardinality of the attribute can be further restricted directly within the profile. This step verifies for all profiles of interest that all attribute cardinalities given by the profile and its attribute definitions are respected by the FDO record.

This step returns for each profile of interest a description of the state of validation which can range between complete success, partial success, and total failure, indicating the validity of the FDO record with respect to attribute cardinalities. Attributes that are used in the FDO record but whose attribute definition is not part of the profile are not validated in this step.

Inputs
The inputs consist of the FDO record, and a list of the FDO profiles to validate the FDO record against. Typically, this is the list of profiles that was returned in .
Outputs
The output is a list of Validated_Profile. A Validated_Profile consists of the following:
  • Profile PID: PID of the FDO profile to be validated
  • Profile_Validation_Status:
    • VALID: All attributes are properly often repeated in the record with respect to the cardinalities in the profile. Note that missing optional fields is acceptable.
    • PARTIALLY_VALID: Some profile required attributes are missing or are not repeated often enough.
    • INVALID: No profile required attributes are found or they are all not repeated often enough.
    • NOT_DEFINED: The FDO profile does not specify any attribute definitions, or the profile cannot be properly interpreted.
  • Attributes_In_Profile: A list with each element being a combination of a
    • the PID of an attribute definition found in the FDO profile and
    • its cardinality. If the cardinality of an attribute was restricted in the profile, this cardinality overrides the original cardinality.
    Empty list when invalid.
  • MissingAttributes: The list of missing required attributes and attributes which are not repeated often enough, with respect to their cardinality. Empty list when VALID.
Expected behavior
The FDO Profile Validation shall process each FDO Profile selected from the FDO Record during and create a list of profile validation status specifying how the FDO Record conforms to each of the FDO Profile’s requirements.

For each FDO Profile selected, the process will acquire its respective FDO and extract from it the FDO profile definition. From this definition it will get the list of attributes and look for them in the FDO Record. Every attribute it finds in the FDO Record will be added to the attributes list. Every required attribute not found in the FDO Record is added to the MissingAttributes list.

The following describes the expected behavior for a given FDO Profile.

  1. If the FDO Profile cannot be mapped to a valid FDO profile definition the process throws one of the following exceptions:
    • ERROR_RESOLVING_FDO: Profile PID cannot be resolved.
    • ERROR_PROFILE_NOT_ACCESSIBLE: The PID resolve but the FDO is not accessible / not valid.
    • ERROR_NO_PROFILE_DEF: No definition found in the FDO profile.
    • ERROR_INVALID_PROFILE: The FDO profile is not a profile definition.
    • ERROR_PARSING_DEFINITION: Illegal or incompatible profile definition.
  2. The FDO Profile has an FDO profile definition and the FDO Record has all the required attributes. The Profile_Validation_Status contains:
    • Status: VALID
    • Attributes: contains the list of all found attributes
    • MissingAttributes: empty.
  3. The FDO Profile has an FDO profile definition and the FDO Record has some of the required attributes. The Profile_Validation_Status contains:
    • Status: PARTIALLY_VALID
    • Attributes: contains the list of found attributes.
    • MissingAttributes: contains the required attributes that are missing.
  4. The FDO Profile has an FDO profile definition and the FDO Record has none of the required attributes. Status: INVALID attributes: contains the list of any optional attributes. MissingAttributes: contains the list of required attributes
An FDO is said to be an instance of a FDO profile when it exhibits all the characteristics the profile specifies.

The validation step resolves each of the FDO profile's PIDs into an FDO record containing the profile's content. Each FDO profile specifies a set of attributes that MUST be present in any FDO that instantiates it, including such things as the names of the attributes, syntax, description, etc.
