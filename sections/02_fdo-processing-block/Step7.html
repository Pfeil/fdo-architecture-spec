[S-7]: FDO Profile Cardinality Validation

Each attribute definition specifies a cardinality with which the respective attribute is allowed to occur in an FDO record. If an attribute definition is part of a profile, the cardinality of the attribute can be further restricted directly within the profile to adapt the attribute to a concrete context. This step verifies for all profiles of interest that all attribute cardinalities given by the profile (that is, cardinalities given by the attribute definitions therein, and restrictions to those) are respected by the FDO record.

This step returns for each profile of interest a description of the state of validation which can range between complete success, partial success, and total failure, indicating the validity of the FDO record with respect to attribute cardinalities. Attributes that are used in the FDO record but whose attribute definition is not part of the profile are not validated in this step.

Inputs
The inputs consist of the FDO record, and a list of the FDO profiles to validate the FDO record against. Typically, this is the list of profiles that was returned in .
Outputs
The output is a list of Validated_Profile. A Validated_Profile consists of the following:
  • Profile PID: PID of the FDO profile to be validated
  • Profile_Validation_Status:
    • VALID: All attributes are properly often repeated in the record with respect to the cardinalities in the profile. Note that missing optional fields is acceptable.
    • PARTIALLY_VALID: Some of the attributes in the profile has the proper number of occurrences in the record.
    • INVALID: None of the attributes in the profile has the proper number of occurrences in the record.
  • Attributes_In_Profile: A list with each element being a combination of
    • the PID of an attribute definition found in the FDO profile and
    • its required cardinality (minimum and maximum). If the cardinality of an attribute was restricted in the profile, this cardinality overrides the original cardinality.
  • Valid_Attributes: A list with each element being a combination of
    • the PID of an attribute definition found in the FDO profile that has the right number of occurrences in the FDO record, and
    • the attribute's number of occurrences in the record.
    Empty list when INVALID.
  • Invalid_Attributes: A list with each element being a combination of
    • the PID of an attribute definition found in the FDO profile that does not have the right number of occurrences in the FDO record, and
    • the attribute's actual number of occurrences in the record.
    Empty list when VALID.
Expected behavior
This step shall process each FDO profile selected from the FDO record during and create a list of Validated_Profile specifying how the FDO record conforms to each of the FDO profile’s attribute definitions.

The following describes the expected behavior for a given FDO profile to generate the Validated_Profile.

  1. For each FDO profile selected, the process will get the list of its attribute definitions and store them in the Attributes_In_Profile list. Then, it checks whether each attribute's cardinality is restricted by the profile. If not, the original cardinality (from the attribute definition) is written to the Attributes_In_Profile list, else the new restricted cardinality.

    If the FDO profile cannot be mapped to a valid list of attribute definitions and cardinalities, the process instead throws one of the following exceptions:

    • ERROR_RESOLVING_FDO: Profile PID cannot be resolved.
    • ERROR_PROFILE_NOT_ACCESSIBLE: The PID resolves but the FDO is not accessible.
    • ERROR_INVALID_PROFILE: The FDO record is not parsable, not interpretable, not a profile, or does not specify any attribute definitions.
  2. The FDO record contains all the attributes given in the profile with the proper number of occurrences. The outputs (additional to Attributes_In_Profile) are:
    • Profile_Validation_Status: VALID
    • Valid_Attributes: contains the list of all found attributes together with their occurrences
    • Invalid_Attributes: empty
  3. The FDO record contains some of the attributes given in the profile with the proper number of occurrences, and some with the wrong number of occurrences. The outputs (additional to Attributes_In_Profile) are
    • Profile_Validation_Status: PARTIALLY_VALID
    • Valid_Attributes: contains the list of valid attributes together with their number of occurrences.
    • Invalid_Attributes: contains the list of invalid attributes together with their number of occurrences.
  4. The FDO record does not contain any of the attributes given in the profile with the proper number of occurrences. The outputs are:
    • Profile_Validation_Status: INVALID
    • Valid_Attributes: empty
    • Invalid_Attributes: contains the list of all found attributes together with their occurrences
